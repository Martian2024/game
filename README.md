<h1>Hi!</h1>
<p>Позвольте представить пример небольшой игры, написанной на Python+PyGame.</p>
<h1>Описание файлов</h1>
<ul>
    <li>main.py - основной файл, запускать его</li>
    <li>camera.py - файл с реализацией класса камеры</li>
    <li>sprites.py - файл с игровыми сущностями</li>
    <li>в папке images находятся все текстуры</li>
</ul>
<h1>Зависимости</h1>
<ul>
    <li>PyGame</li>
    <li>pygame_gui</li>
</ul>
<p>В директории проекта находится файл requirements.txt для быстрой установки зависимостей</p>
<h1>Запуск</h1>
<p>Необходимо запустить файл main.py</p>
